# XULURY - AI Luxury Bag Identifier

XULURY is an AI-powered web application that helps users instantly identify luxury handbags.

By simply uploading an image of a handbag, XULURY utilizes advanced AI image recognition (powered by Gemini) to analyze the silhouette, hardware, and design details. It then provides users with:
- The exact brand and model name
- An estimated market price range
- High-quality reference images of the bag
- Direct shopping links (prioritizing the official brand site)
- Alternative matches

## Tech Stack
- **Frontend**: Next.js, React, Tailwind CSS, Base UI, Framer Motion
- **Backend**: FastAPI (Python), Google Gemini API
- **Database / Storage**: Supabase
